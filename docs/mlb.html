MLB Runs v1 estimates each team's scoring from recent offense and opponent run prevention, shrunk toward league scoring to reduce small-sample noise. It then converts projected run distributions into win probabilities. This is the first production baseline; starting-pitcher, bullpen, park and lineup features can be layered into the next version and validated out-of-sample.
